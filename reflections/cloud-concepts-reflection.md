# Cloud Concepts Reflection

Cloud computing has become an important part of my daily life because many of the applications I use depend on cloud technology. Three cloud services that I regularly use are **GCash**, **Google Drive**, and **Messenger**. These applications make everyday tasks more convenient by allowing me to make cashless payments, store important files online, and communicate with friends, classmates, and family wherever I am.

GCash is a **Software as a Service (SaaS)** application because it allows users to perform digital payments, money transfers, and other financial transactions through a ready-to-use application without managing the underlying servers or infrastructure. It uses a **Public Cloud** deployment model because the service is available to millions of users through the internet. Google Drive is also a **SaaS** application because it provides cloud storage and file-sharing services that users can access from any device with an internet connection. It is classified as a **Public Cloud** service since Google's cloud infrastructure is shared among users while keeping each person's files secure. Messenger is another **SaaS** application because it offers instant messaging, voice calls, video calls, and file sharing without requiring users to manage the technology behind the service. It also uses a **Public Cloud** deployment model because it is accessible to anyone with an account through Meta's online cloud platform.

Version control is essential when working on cloud projects because it keeps a complete history of changes, making it easier to correct mistakes and recover previous versions if needed. Git and GitHub help developers collaborate efficiently by allowing multiple team members to work on the same project without overwriting each other's work. GitHub also provides features such as pull requests, commit history, and version tracking, which make it easier to review changes, identify errors, and maintain an organized and reliable cloud computing project.
